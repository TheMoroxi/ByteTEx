# Wymiana dysku HDD na SSD

## Wprowadzenie

Dysk SSD znacznie przyspiesza komputer dzięki krótszemu czasowi dostępu do danych.

## Zalety SSD

- szybszy start Windows,
- szybsze uruchamianie programów,
- cicha praca,
- mniejsze zużycie energii.

## Wymiana

1. Wykonaj kopię danych.
2. Odłącz stary dysk.
3. Zamontuj SSD.
4. Zainstaluj system lub sklonuj dysk.

## Po instalacji

Sprawdź:
- wykrywanie dysku,
- tryb AHCI,
- aktualizacje sterowników.
