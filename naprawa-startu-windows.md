# Naprawa uruchamiania Windows

## Objawy

- Windows nie startuje,
- pojawia się automatyczna naprawa,
- komputer restartuje się.

## Przyczyny

- uszkodzone pliki systemowe,
- błędy dysku,
- niepoprawna aktualizacja.

## Rozwiązania

Można użyć:

- naprawy podczas startu,
- punktu przywracania,
- wiersza poleceń.
