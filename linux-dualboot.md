# Instalacja Linux obok Windows

## Czym jest dual boot?

Dual boot pozwala korzystać z dwóch systemów operacyjnych na jednym komputerze.

## Przygotowanie

Potrzebujesz:

- pendrive minimum 8 GB
- obraz ISO Linux
- program Rufus

## Instalacja

1. Utwórz bootowalny pendrive.
2. Uruchom komputer z USB.
3. Wybierz instalację obok Windows.
4. Przydziel miejsce na dysku.
5. Zainstaluj system.

## Popularne dystrybucje

- Ubuntu
- Linux Mint
- Fedora

## Uwaga

Przed instalacją wykonaj kopię ważnych danych.
