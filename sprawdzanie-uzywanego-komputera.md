# Jak sprawdzić używany komputer przed zakupem

## Wprowadzenie

Kupno używanego komputera może być dobrym sposobem na zaoszczędzenie pieniędzy, ale przed zakupem warto dokładnie sprawdzić stan sprzętu. Ten poradnik pokazuje, na co zwrócić uwagę i jak wykryć najczęstsze problemy.

---

# 1. Sprawdzenie wyglądu komputera

Przed uruchomieniem sprawdź:

- czy obudowa nie jest mocno uszkodzona,
- czy nie ma śladów zalania,
- czy wszystkie porty działają,
- czy wentylatory nie są uszkodzone,
- czy śruby nie wyglądają na często odkręcane.

---

# 2. Sprawdzenie podzespołów

W systemie Windows sprawdź:

## Procesor

Sprawdź:
- model CPU,
- liczbę rdzeni,
- taktowanie.

Możesz użyć:
- Menedżera zadań,
- CPU-Z.

---

## Pamięć RAM

Sprawdź:

- ilość RAM,
- częstotliwość,
- czy działa w dwóch kanałach.

Przykład:

```
16 GB DDR4 3200 MHz
```

jest lepsze niż:

```
8 GB DDR4 2133 MHz
```

---

## Karta graficzna

Sprawdź:

- dokładny model GPU,
- temperatury,
- działanie wentylatorów.

Testy:

- gra,
- benchmark,
- test obciążeniowy.

---

# 3. Sprawdzenie dysku

Dysk jest jednym z najważniejszych elementów.

Sprawdź:

- stan SMART,
- liczbę przepracowanych godzin,
- błędy sektorów.

Programy:

- CrystalDiskInfo,
- HD Tune.

Unikaj komputerów z:

- dużą liczbą błędów SMART,
- uszkodzonymi sektorami,
- bardzo starymi dyskami HDD.

---

# 4. Test pamięci RAM

Uszkodzona pamięć RAM może powodować:

- zawieszanie systemu,
- restarty,
- BSOD.

Program:

- MemTest86

Test powinien zakończyć się bez błędów.

---

# 5. Sprawdzenie temperatur

Podczas obciążenia sprawdź:

## Procesor

Normalnie:

- około 40–70°C podczas pracy,
- wyższe wartości mogą oznaczać problem.

## Karta graficzna

Sprawdź:

- temperaturę,
- prędkość wentylatorów.

Programy:

- HWMonitor,
- HWiNFO.

---

# 6. Test zasilacza

Zasilacz jest bardzo ważny.

Sprawdź:

- markę,
- moc,
- wiek,
- certyfikat.

Unikaj tanich zasilaczy bez znanego producenta.

---

# 7. Sprawdzenie systemu Windows

Sprawdź:

- czy system się uruchamia,
- czy nie ma błędów,
- czy działa aktywacja,
- czy wszystkie sterowniki są zainstalowane.

---

# 8. Test wydajności

Wykonaj kilka testów:

## Procesor

Programy:

- Cinebench

## Karta graficzna

Programy:

- 3DMark
- FurMark

## Dysk

Programy:

- CrystalDiskMark

---

# 9. Sprawdzenie baterii laptopa

W przypadku laptopa sprawdź:

- kondycję baterii,
- czas pracy,
- ładowanie.

Komenda Windows:

```
powercfg /batteryreport
```

Tworzy raport baterii.

---

# Podsumowanie

Dobry używany komputer powinien:

- działać stabilnie,
- mieć sprawne podzespoły,
- nie przegrzewać się,
- posiadać zdrowy dysk,
- mieć markowy zasilacz.

Dokładne sprawdzenie sprzętu przed zakupem może uchronić przed drogą naprawą.
