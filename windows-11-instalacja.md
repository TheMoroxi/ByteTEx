# 🖥️ Instalacja Windows 11

## Opis
Instrukcja przygotowania komputera oraz instalacji systemu Windows 11 od podstaw.

## Wymagania Windows 11
Przed instalacją sprawdź:

- Procesor 64-bitowy zgodny z Windows 11.
- Minimum 4 GB pamięci RAM.
- Minimum 64 GB wolnego miejsca na dysku.
- Obsługę TPM 2.0.
- Włączony Secure Boot.
- Dostęp do internetu (zalecane).

## Potrzebne rzeczy

- Pendrive minimum 8 GB.
- Obraz ISO Windows 11.
- Program do tworzenia bootowalnego pendrive.
- Klucz produktu Windows (opcjonalnie podczas instalacji).

## Przygotowanie pendrive

1. Pobierz oficjalny obraz Windows 11.
2. Podłącz pendrive do komputera.
3. Uruchom program do tworzenia nośnika instalacyjnego.
4. Wybierz plik ISO Windows 11.
5. Wybierz pendrive.
6. Rozpocznij tworzenie nośnika.

Uwaga: wszystkie dane z pendrive zostaną usunięte.

## Uruchomienie instalatora

1. Podłącz przygotowany pendrive do komputera.
2. Uruchom komputer ponownie.
3. Wejdź do menu bootowania:
   - F12,
   - F11,
   - ESC,
   - DEL (zależnie od producenta).
4. Wybierz pendrive jako urządzenie startowe.

## Instalacja Windows 11

1. Wybierz język systemu.
2. Kliknij **Zainstaluj teraz**.
3. Wprowadź klucz produktu lub pomiń ten krok.
4. Wybierz edycję Windows.
5. Zaakceptuj warunki licencji.
6. Wybierz typ instalacji:
   - Aktualizacja,
   - Instalacja niestandardowa.

## Partycjonowanie dysku

Podczas czystej instalacji można:

- Usunąć stare partycje.
- Utworzyć nowe partycje.
- Wybrać istniejącą partycję systemową.

⚠️ Usunięcie partycji usuwa znajdujące się na niej dane.

## Pierwsza konfiguracja

Po instalacji:

1. Połącz komputer z internetem.
2. Utwórz konto użytkownika.
3. Ustaw zabezpieczenia.
4. Poczekaj na konfigurację systemu.

## Instalacja sterowników

Po uruchomieniu Windows:

- Zainstaluj sterowniki chipsetu.
- Zainstaluj sterownik karty graficznej.
- Sprawdź aktualizacje Windows Update.
- Zainstaluj brakujące sterowniki urządzeń.

## Najczęstsze problemy

### Komputer nie startuje z pendrive
Sprawdź:
- Kolejność bootowania w BIOS.
- Czy pendrive został poprawnie utworzony.
- Tryb UEFI.

### Brak dysku podczas instalacji
Możliwe rozwiązania:
- Sprawdzenie ustawień BIOS.
- Instalacja sterownika kontrolera dysku.
- Zmiana trybu SATA.

### Windows 11 nie spełnia wymagań
Sprawdź:
- TPM 2.0.
- Secure Boot.
- Aktualizację BIOS.

## Bezpieczeństwo

- Wykonaj kopię ważnych danych przed instalacją.
- Nie usuwaj partycji bez upewnienia się, że nie zawierają potrzebnych plików.
- Pobieraj system tylko z zaufanych źródeł.

## Podsumowanie

Prawidłowa instalacja Windows 11 wymaga przygotowania nośnika, poprawnej konfiguracji BIOS oraz instalacji sterowników po pierwszym uruchomieniu.
