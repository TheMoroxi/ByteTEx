# Instalacja sterowników Windows

## Poziom trudności

⭐⭐ Łatwy / Średni


## Opis

Sterowniki umożliwiają systemowi Windows poprawną komunikację ze sprzętem komputera. Odpowiadają między innymi za działanie karty graficznej, dźwięku, Wi-Fi, Bluetooth oraz innych urządzeń.


## Potrzebne rzeczy

- Dostęp do internetu
- Model komputera lub podzespołu
- Pendrive (opcjonalnie)
- Konto administratora Windows


## Sprawdzenie brakujących sterowników

1. Kliknij prawym przyciskiem myszy na Start.

2. Otwórz:

Menedżer urządzeń

3. Sprawdź urządzenia oznaczone żółtym symbolem ⚠️.

4. Kliknij urządzenie prawym przyciskiem.

5. Wybierz:

Właściwości → Szczegóły

aby sprawdzić model sprzętu.


## Metoda 1 - Windows Update

1. Otwórz Ustawienia.

2. Wejdź w:

Windows Update

3. Kliknij:

Sprawdź aktualizacje

4. Otwórz:

Opcje zaawansowane → Aktualizacje opcjonalne → Aktualizacje sterowników

5. Zainstaluj dostępne sterowniki.


## Metoda 2 - Strona producenta

Najbezpieczniejsza metoda instalacji.

Przykłady producentów:

- NVIDIA - karty graficzne
- AMD - procesory i karty graficzne
- Intel - chipset i grafika
- Lenovo / ASUS / HP / Dell - sterowniki do laptopów i komputerów


Kroki:

1. Znajdź model urządzenia.

2. Wejdź na stronę producenta.

3. Pobierz sterownik dla swojej wersji Windows.

4. Uruchom instalator.

5. Uruchom ponownie komputer.


## Instalacja sterownika karty graficznej

1. Pobierz sterownik GPU.

2. Uruchom instalator.

3. Wybierz instalację niestandardową, jeśli jest dostępna.

4. Wykonaj czystą instalację.

5. Zrestartuj komputer.


## Aktualizacja ręczna

1. Otwórz Menedżer urządzeń.

2. Kliknij urządzenie.

3. Wybierz:

Aktualizuj sterownik

4. Wybierz:

Wyszukaj sterowniki automatycznie


## Najczęstsze problemy


### Brak internetu po instalacji Windows

Przyczyny:

- brak sterownika Wi-Fi,
- brak sterownika karty sieciowej.


Rozwiązanie:

1. Pobierz sterownik na innym komputerze.

2. Przenieś plik przez pendrive.

3. Zainstaluj ręcznie.


### Zły sterownik

Objawy:

- błędy systemu,
- brak działania urządzenia,
- problemy z wydajnością.


Rozwiązanie:

1. Otwórz Menedżer urządzeń.

2. Usuń nieprawidłowy sterownik.

3. Zainstaluj poprawną wersję.


## Ostrzeżenia

⚠️ Nie pobieraj sterowników z podejrzanych stron.

⚠️ Unikaj nieznanych programów automatycznie instalujących sterowniki.

⚠️ Zawsze sprawdzaj dokładny model sprzętu.


## Po instalacji sprawdź

- dźwięk,
- Wi-Fi,
- Bluetooth,
- USB,
- kartę graficzną,
- działanie urządzeń.


## Podsumowanie

Poprawnie zainstalowane sterowniki zapewniają stabilną pracę systemu Windows oraz pełną wydajność podzespołów.
