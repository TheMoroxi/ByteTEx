# Diagnostyka problemów z komputerem PC

## Poziom trudności

⭐⭐ Łatwy / Średni


## Opis

Diagnostyka komputera polega na sprawdzeniu sprzętu oraz systemu w celu znalezienia przyczyny problemów.

Może pomóc w przypadku:

- wolnego działania,
- zawieszania się systemu,
- braku obrazu,
- dziwnych dźwięków,
- restartów,
- przegrzewania.


# Przygotowanie

Przed rozpoczęciem:

- zapisz ważne dane,
- wyłącz komputer przed sprawdzaniem podzespołów,
- przygotuj podstawowe narzędzia.


## Potrzebne narzędzia

- Śrubokręt
- Latarka
- Pendrive
- Programy diagnostyczne
- Kabel zasilający sprawny


# 1. Sprawdzenie podstawowych rzeczy

Sprawdź:

- czy komputer jest podłączony do prądu,
- czy kabel zasilający działa,
- czy monitor jest włączony,
- czy wszystkie przewody są poprawnie podłączone.


# 2. Brak uruchamiania komputera

Objawy:

- komputer nie reaguje,
- brak wentylatorów,
- brak diod.


Sprawdź:

1. Zasilacz.

2. Kabel zasilający.

3. Przycisk Power.

4. Podłączenie płyty głównej.


# 3. Komputer uruchamia się, ale nie ma obrazu

Możliwe przyczyny:

- problem z kartą graficzną,
- źle podłączony kabel monitora,
- uszkodzona pamięć RAM.


Sprawdź:

1. Kabel HDMI/DisplayPort.

2. Czy monitor działa.

3. Wyjmij i włóż ponownie RAM.

4. Sprawdź kartę graficzną.


# 4. Test pamięci RAM

Uszkodzona pamięć RAM może powodować:

- niebieskie ekrany,
- restarty,
- zawieszanie.


Możesz użyć:

Windows Memory Diagnostic


Kroki:

1. Wyszukaj:

Diagnostyka pamięci systemu Windows

2. Uruchom test.

3. Poczekaj na wynik.


# 5. Sprawdzenie dysku

Problemy z dyskiem mogą powodować:

- wolne uruchamianie,
- błędy systemu,
- utratę danych.


Sprawdź:

- ilość wolnego miejsca,
- stan SMART,
- błędy dysku.


Przykładowe narzędzia:

- CrystalDiskInfo
- CHKDSK Windows


# 6. Sprawdzanie temperatur

Za wysokie temperatury mogą powodować:

- spadki wydajności,
- wyłączanie komputera,
- głośną pracę wentylatorów.


Sprawdź:

- procesor CPU,
- kartę graficzną GPU,
- dysk.


# 7. Problemy z systemem Windows

Objawy:

- błędy podczas uruchamiania,
- wolne działanie,
- programy się zamykają.


Możliwe rozwiązania:

- aktualizacja Windows,
- sprawdzenie sterowników,
- skanowanie systemu.


Polecenie sprawdzania plików systemowych:


# 8. Niebieski ekran BSOD

BSOD może być spowodowany przez:

- sterowniki,
- RAM,
- dysk,
- przegrzewanie.


Sprawdź:

- kod błędu,
- ostatnio instalowane programy,
- aktualizacje sterowników.


# 9. Dziwne dźwięki komputera

Możliwe źródła:

### Wentylatory

Problem:

- kurz,
- zużyte łożyska.


### Dysk HDD

Problem:

- uszkodzenia mechaniczne.


### Zasilacz

Problem:

- awaria,
- niestabilne napięcia.


# 10. Sprawdzenie podzespołów

Podstawowa lista:

| Element | Co sprawdzić |
|---|---|
| RAM | Błędy pamięci |
| Dysk | Stan i błędy |
| CPU | Temperatury |
| GPU | Temperatury i obraz |
| Zasilacz | Stabilność pracy |


# Najczęstsze problemy


## Komputer wolno działa

Sprawdź:

- dysk,
- RAM,
- programy startowe,
- temperatury.


## Komputer się restartuje

Sprawdź:

- temperatury,
- zasilacz,
- pamięć RAM.


## Brak internetu

Sprawdź:

- kabel sieciowy,
- sterownik karty sieciowej,
- router.


# Bezpieczeństwo

⚠️ Odłącz komputer od prądu przed otwieraniem obudowy.

⚠️ Nie dotykaj podzespołów mokrymi rękami.

⚠️ Nie rozbieraj zasilacza.


# Podsumowanie

Prawidłowa diagnostyka pozwala szybko znaleźć przyczynę problemu.

Najpierw sprawdzaj:

1. Zasilanie.
2. Połączenia.
3. Temperatury.
4. RAM.
5. Dysk.
6. Sterowniki.

Dzięki podstawowej diagnostyce można naprawić wiele problemów bez wymiany całego komputera.
