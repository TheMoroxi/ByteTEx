# 🧪 Testowanie pamięci RAM

## Opis
Instrukcja sprawdzania pamięci RAM pod kątem błędów, niestabilności oraz problemów powodujących awarie komputera.

## Objawy uszkodzonej pamięci RAM

Problemy z RAM mogą powodować:

- Losowe restarty komputera.
- Niebieski ekran Windows (BSOD).
- Zawieszanie systemu.
- Błędy podczas uruchamiania programów.
- Problemy z instalacją systemu.
- Niepoprawne działanie gier.

## Przygotowanie do testu

Przed rozpoczęciem:

1. Zapisz wszystkie ważne pliki.
2. Zamknij działające programy.
3. Sprawdź, ile pamięci RAM posiada komputer.
4. Jeśli komputer był otwierany, sprawdź poprawność montażu modułów.

## Sprawdzenie fizyczne RAM

1. Wyłącz komputer.
2. Odłącz kabel zasilający.
3. Otwórz obudowę.
4. Wyjmij moduły RAM.
5. Sprawdź:
   - Czy styki są czyste.
   - Czy pamięć nie jest uszkodzona mechanicznie.
   - Czy moduł jest poprawnie zamontowany.

## Czyszczenie pamięci RAM

1. Wyjmij moduł RAM.
2. Delikatnie oczyść styki.
3. Usuń kurz z gniazda pamięci.
4. Zamontuj RAM ponownie.

Nie dotykaj palcami złotych styków.

## Test pamięci w Windows

Windows posiada wbudowane narzędzie:

1. Otwórz menu Start.
2. Wyszukaj:
   **Diagnostyka pamięci systemu Windows**.
3. Uruchom narzędzie.
4. Wybierz ponowne uruchomienie komputera.
5. Poczekaj na zakończenie testu.

## Test za pomocą specjalnych programów

Zaawansowane testy można wykonać przy pomocy narzędzi diagnostycznych uruchamianych z pendrive.

Podczas testu sprawdzane są:
- Błędy zapisu.
- Błędy odczytu.
- Stabilność pamięci.

## Sprawdzanie wielu kości RAM

Jeżeli komputer posiada kilka modułów:

1. Wyjmij wszystkie kości.
2. Uruchamiaj komputer z jedną kością.
3. Testuj każdy moduł osobno.
4. Sprawdź różne sloty RAM.

Pozwala to znaleźć uszkodzony element.

## Problemy z kompatybilnością RAM

Problemy mogą wystąpić gdy:

- Moduły mają różne parametry.
- Pamięć nie obsługuje płyty głównej.
- Ustawiono zbyt wysokie taktowanie.
- Profil XMP jest niestabilny.

## Po wymianie RAM

Po instalacji nowej pamięci:

1. Sprawdź ilość wykrytej pamięci.
2. Uruchom test stabilności.
3. Sprawdź temperatury.
4. Przetestuj działanie programów.

## Najczęstsze błędy

- Źle włożona kość RAM.
- Brudne styki.
- Niekompatybilna pamięć.
- Uszkodzony slot na płycie głównej.

## Bezpieczeństwo

Przed pracą wewnątrz komputera:

- Odłącz zasilanie.
- Rozładuj ładunki elektrostatyczne.
- Nie używaj siły podczas montażu.

## Podsumowanie

Testowanie RAM pozwala wykryć problemy powodujące niestabilność komputera. Regularna diagnostyka pomaga uniknąć utraty danych i awarii systemu.
