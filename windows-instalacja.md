# Instalacja Windows

## Poziom trudności

⭐⭐ Średni


## Potrzebne narzędzia

- Pendrive minimum 8 GB
- Komputer z dostępem do internetu
- Program do tworzenia nośnika instalacyjnego
- Klucz produktu Windows (opcjonalnie)


## Przygotowanie pendrive

1. Pobierz narzędzie instalacyjne Windows z oficjalnej strony Microsoft.

2. Podłącz pusty pendrive USB.

3. Uruchom narzędzie tworzenia nośnika.

4. Wybierz opcję utworzenia instalatora USB.

5. Poczekaj na zakończenie procesu.


## Uruchomienie instalatora

1. Podłącz pendrive do komputera.

2. Uruchom ponownie komputer.

3. Wejdź do menu BIOS/UEFI.

4. Wybierz start z urządzenia USB.

5. Uruchomi się instalator Windows.


## Instalacja systemu

1. Wybierz język oraz układ klawiatury.

2. Kliknij przycisk "Zainstaluj teraz".

3. Wprowadź klucz produktu lub pomiń ten krok.

4. Wybierz wersję systemu Windows.

5. Zaakceptuj warunki licencji.

6. Wybierz dysk docelowy.

7. Rozpocznij instalację.


## Po instalacji

- Zainstaluj sterowniki.
- Wykonaj aktualizacje Windows.
- Zainstaluj potrzebne programy.
- Utwórz punkt przywracania systemu.


## Rozwiązywanie problemów

### Komputer nie startuje z pendrive

Sprawdź:

- kolejność bootowania w BIOS/UEFI,
- czy pendrive został poprawnie utworzony,
- czy port USB działa.


### Brak sterowników

Pobierz sterowniki ze strony producenta komputera lub podzespołów.


## Ostrzeżenie

Instalacja systemu może usunąć dane z dysku.

Przed rozpoczęciem wykonaj kopię zapasową ważnych plików.
