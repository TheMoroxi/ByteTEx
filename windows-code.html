🛠️ Komendy CMD do naprawy Windows

Sprawdzanie plików systemowych SFC

Naprawia uszkodzone pliki systemowe Windows.

sfc /scannow

Naprawa obrazu systemu DISM

Naprawia składniki systemu Windows.

DISM /Online /Cleanup-Image /RestoreHealth

Sprawdzenie dysku

Wyszukuje i naprawia błędy dysku.

chkdsk C: /f /r

Naprawa wpisów rozruchowych

Pomaga gdy Windows nie startuje.


bootrec /fixmbr
bootrec /scanos
bootrec /rebuildbcd

Reset stosu sieciowego

Naprawia problemy z internetem.


netsh winsock reset
netsh int ip reset
ipconfig /flushdns

Sprawdzenie sterowników

Tworzy raport problemów ze sterownikami.


driverquery

Tryb naprawy Windows

Restart do środowiska odzyskiwania.


shutdown /r /o /f /t 0
