# Czyszczenie Windows

## Dlaczego warto?

Z czasem system gromadzi:

- pliki tymczasowe,
- cache,
- stare aktualizacje.

## Czyszczenie

Można użyć:

- Oczyszczanie dysku,
- ustawienia pamięci,
- ręczne usuwanie plików tymczasowych.

## Efekt

- więcej wolnego miejsca,
- lepsza organizacja systemu.
