# Wymiana pasty termicznej

## Czym jest pasta?

Pasta termiczna poprawia przewodzenie ciepła między procesorem a chłodzeniem.

## Objawy starej pasty

- wysokie temperatury,
- głośna praca wentylatora,
- spadki wydajności.

## Wymiana

1. Zdejmij chłodzenie.
2. Usuń starą pastę.
3. Wyczyść powierzchnię.
4. Nałóż nową pastę.
5. Zamontuj chłodzenie.

## Uwaga

Nie używaj zbyt dużej ilości pasty.
