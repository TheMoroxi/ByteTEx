# Instalacja i wymiana pamięci RAM

## Wprowadzenie

Pamięć RAM odpowiada za tymczasowe przechowywanie danych używanych przez system i programy.

Większa ilość RAM może poprawić:
- płynność pracy,
- działanie wielu programów,
- wydajność w grach.

## Sprawdzenie kompatybilności

Przed zakupem sprawdź:

- typ pamięci (DDR4, DDR5),
- maksymalną ilość obsługiwaną przez płytę,
- taktowanie.

## Montaż

1. Wyłącz komputer.
2. Odłącz zasilanie.
3. Otwórz obudowę.
4. Włóż moduł RAM w odpowiednie gniazdo.
5. Dociśnij do zatrzaśnięcia.

## Po instalacji

Sprawdź pamięć w:
- BIOS/UEFI,
- Menedżerze zadań Windows.
